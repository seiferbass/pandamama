管理員工

雲端即時同步設定

設定後，排班會即時存到雲端；部署一次含設定的網頁，之後你在任何裝置修改，別人開著網頁就會自動更新，不必再重傳。

  1. 到 console.firebase.google.com 用 Google 帳號建立一個專案（免費）。
  2. 左側選 Build → Realtime Database → 建立資料庫，位置隨意，規則先選「以測試模式開始」。
  3. 建好後，點資料庫規則頁，把規則改成下面這段並發佈（測試模式 30 天會失效，這段不會）：
    { "rules": { ".read": true, ".write": true } }
  4. 回專案設定（齒輪 → 專案設定 → 一般），在「你的應用程式」建立一個 網頁應用程式 </>，複製它給的 firebaseConfig 整段。
  5. 把整段貼到下面欄位，按「儲存並連線」。

留空欄位並儲存＝關閉雲端、回到離線模式。此設定只存在此裝置；正式讓大家看到，要按下方「匯出部署檔」再上傳一次。
提醒：上述規則為公開讀寫，適合內部小團隊；資料可隨時用「備份檔」另存。若日後需要更嚴格權限，可再加 Firebase 登入驗證。
